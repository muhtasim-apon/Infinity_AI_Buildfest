# Contributing

## Branching
`main` is protected. Work on `feat/<scope>`, `fix/<scope>`, `docs/<scope>`.

## Commits
Conventional Commits, e.g. `feat(routing): add corridor cost predictor interface`.

## Definition of done

- [ ] Stub carries a docstring stating its contract, inputs, outputs and failure modes
- [ ] Any new statistic is sourced in `docs/research/data/`
- [ ] Any new model has a model card in `docs/ai/model-cards/`
- [ ] Any architectural choice has an ADR
- [ ] Bangla strings added to `app_bn.arb` alongside English
- [ ] `docs/congress/rubric-map.md` updated if the change affects a rubric line
