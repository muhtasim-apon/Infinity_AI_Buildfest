# Core

Cross-cutting client infrastructure: network, storage, error taxonomy, the offline
outbox (ADR 0008), connectivity, analytics with a PII scrubber (ADR 0011), feature
flags, and Bangla-first localisation (ADR 0012).

See `l10n/bdt_formatter.dart` - lakh/crore grouping and Bengali numerals - and
`offline/outbox_queue.dart`.
