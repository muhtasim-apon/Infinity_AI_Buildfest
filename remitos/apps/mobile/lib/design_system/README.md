# Design System

Tokens, shared components, and the two accessibility modes.

The type scale is set from **Bengali** metrics first; Latin fits it (ADR 0012).
Every actionable component carries an icon, never text alone.

| Mode | Purpose |
|---|---|
| `modes/low_bandwidth` | Under 50 KB per screen - system fonts, no imagery |
| `modes/elder` | Enlarged targets and type, higher contrast, fewer items per screen |
