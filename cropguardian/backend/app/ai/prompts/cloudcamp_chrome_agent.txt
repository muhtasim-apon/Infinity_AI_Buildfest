PROJECT NAME
CropGuardian

PROJECT SUMMARY
CropGuardian is a bilingual, safety-focused AI assistant for Bangladeshi rice farmers. A farmer uploads a crop photograph, the application performs multimodal analysis through Meta's Model API, returns a calibrated diagnosis or abstains when evidence is insufficient, retrieves relevant curated BRRI guidance, and presents cited advice. Potential regional outbreaks require human reviewer approval before farmers see an alert.
